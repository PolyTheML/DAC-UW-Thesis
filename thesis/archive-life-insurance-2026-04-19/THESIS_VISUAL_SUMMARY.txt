LAYER 2: DRIFT MONITORING (PSI-BASED)
────────────────────────────────────────────────────────────────────────────────

Historical Applicant Distribution (Baseline: mortality_ratio bins)

Bin [0.0, 1.0): 0%     - Low-risk baseline
Bin [1.0, 1.5): 53.4%  - Expected: 35%
Bin [1.5, 2.0): 25.3%  - Expected: 25%
Bin [2.0, 2.5): 14.7%  - Expected: 15%
...higher bins...

Compare NEW applicant batch to baseline:

PSI = Σ (actual% - baseline%) × ln(actual% / baseline%)

PSI < 0.10    → GREEN   (no drift) ✅ Stable population
0.10 ≤ PSI < 0.25 → AMBER   (moderate drift) ⚠️ Monitor
PSI ≥ 0.25    → RED    (significant drift) 🚨 Investigate!

Alert Underwriting Team → Trigger Recalibration if PSI > 0.25

EXPERIMENT 3: ADVERSARIAL FAILURE MODES
────────────────────────────────────────
(In progress — ready to run)

Failure Mode 1: LABEL DRIFT (Comorbidity Confounding)
  Scenario: New clinic manages diabetic BP → normal
  Mortality Ratio: stays same
  Input Features: BP distribution changes
  PSI Alert: GREEN ✗ (silent failure)
  Fix: Monitor feature co-occurrence PSI

Failure Mode 2: FEATURE-PSI DECOUPLING (Age Cohort Shift)
  Scenario: Young professionals (age 22-28) enter
  Mortality Ratio: 1.0 (healthy, matches reference bin)
  Age Distribution: mean 25 vs baseline 38 (HUGE shift)
  PSI Alert: GREEN ✗ (misses age shift)
  Fix: Monitor marginal age distribution PSI

Failure Mode 3: BIN EDGE CAMOUFLAGE (Tier Boundary)
  Scenario: 15% shift from MR 1.48 → 1.73 (cross 1.5 boundary)
  Risk Tier: changes from LOW → MEDIUM
  HITL Queue: escalation rate doubles
  PSI Alert: GREEN ✗ (small relative shift)
  Fix: Monitor HITL escalation rate + use finer bins near boundaries

Key Finding: PSI ALONE IS INSUFFICIENT
Recommendation: MULTI-METRIC MONITORING
  • Primary: PSI on mortality_ratio
  • Secondary: Feature co-occurrence PSI (label drift)
  • Secondary: Marginal age distribution PSI (cohort shift)
  • Secondary: HITL escalation rate (boundary sensitivity)

Result: 🔬 Ready to run (framework validated)
